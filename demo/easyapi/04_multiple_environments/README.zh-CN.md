# 04 — 多环境

[English](README.md) | [简体中文](README.zh-CN.md)

## 面向对象

适合需要批量状态，同时希望显式控制每个环境的开发者。

## 前置条件

理解案例 02 和 03 中的刚体与铰接物体命令。

```bash
PYTHONPATH=src python demo/easyapi/04_multiple_environments/main.py
```

## 预期结果

只有环境 0 和 2 发生运动。重置环境 2 后，仅它的关节值恢复；环境 0 和 1 不变。

## 代码讲解

`num_envs=3` 在一个世界中请求三个环境。两行的力命令和关节 target 矩阵与 `environments=(0,2)` 一一对应。读取状态时仍然得到三行，每个环境一行。`reset((2,))` 执行局部重置，并返回指出受影响环境的 `ResetResult`。断言同时检查命令路由和环境隔离。

## 常见错误

- 指定环境列表后，target 第一维长度必须与列表长度相同。
- 环境索引必须唯一，并且处于 `[0, num_envs)` 范围内。
- 真实后端的可见窗口模式可能比无头模式支持更少环境，应通过能力协商判断。

## 验收级别

无第三方依赖的批量命令、状态与局部重置合同测试。
